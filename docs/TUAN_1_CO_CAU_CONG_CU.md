### 1. Giới thiệu về Công ty Cổ phần Công nghệ TFL
- **Tên doanh nghiệp:** Công ty Cổ phần Công nghệ TFL.
- **Lĩnh vực hoạt động:** Phát triển phần mềm, giải pháp chuyển đổi số, hệ thống thông tin phục vụ an ninh trật tự, giám sát công cộng và các giải pháp quản lý doanh nghiệp/tổ chức.
- **Cơ cấu tổ chức:**
  - Ban Giám đốc điều hành.
  - Khối Phát triển sản phẩm (Phòng R&D, Đội ngũ Lập trình viên Frontend/Backend/Mobile).
  - Khối Quản trị chất lượng & Vận hành (Đội Tester, DevOps, Triển khai & Nghiệm thu dự án).
  - Khối Hành chính - Nhân sự.

### 2. Văn hóa làm việc và quy định tại doanh nghiệp
- **Môi trường:** Năng động, chuyên nghiệp, khuyến khích tính tự chủ, tinh thần học hỏi công nghệ mới và chia sẻ tri thức.
- **Quy trình làm việc:** Áp dụng mô hình linh hoạt (Agile/Scrum), họp giao ban định kỳ (Daily standup / Weekly sprint planning).
- **Quy định bảo mật thông tin:**
  - Tuyệt đối bảo mật dữ liệu khách hàng và các dự án của đối tác (đặc biệt là các dự án liên quan đến cơ quan nhà nước, công an).
  - Tuân thủ quy tắc quản lý mã nguồn, không công khai mã nguồn hoặc secret/API keys lên các kho lưu trữ công cộng.

### 3. Cài đặt và cấu hình công cụ làm việc
Để chuẩn bị cho dự án "Xây dựng hệ thống quản lý ký túc xá tích hợp AI", các công cụ sau đã được cài đặt và cấu hình thành công:
1. **Node.js & npm:**
   - Phiên bản Node.js: `v25.2.1` (hỗ trợ đầy đủ các tính năng JavaScript ES/TS hiện đại).
   - Phiên bản npm: `11.6.2`.
2. **Hệ quản trị CSDL:**
   - MySQL Server 8.4 (Dịch vụ `MySQL84_New` đang hoạt động ổn định trên cổng mặc định 3306).
   - Công cụ quản trị CSDL: MySQL Workbench / DBeaver / Navicat / Prisma Studio.
3. **Môi trường phát triển tích hợp (IDE):**
   - Visual Studio Code với các tiện ích mở rộng (Extensions): *Prisma, ESLint, Prettier, Thunder Client/Postman*.
4. **Hệ thống quản lý phiên bản mã nguồn:**
   - Git phiên bản 2.52.0. Đã thiết lập cấu hình `user.name`, `user.email` và khởi tạo Git repository cho dự án với `.gitignore` bảo vệ file `.env`.
5. **Công cụ AI & API Client:**
   - Google AI Studio (Chuẩn bị tài khoản và API Key cho mô hình Google Gemini).
